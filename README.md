# prodpilot-negatives

Generated research data for ProdPilot (BSAI-FYP-2026). Do not use anything here
as an example of how to build or deploy anything.

Each commit in this repository's history is one deliberately broken copy of a
permissively licensed open source project, produced by module 5.1's controlled
breakage step. Module 5.3 deploys each commit to Render and records whether it
actually deploys and passes the post-deploy smoke test, which is the label the
Phase 5 model trains on.

Every credential appearing in this history is fabricated. The string beginning
sk_live_ is not a real key and never was. It exists so that the secret scanning
rules SCR-002 and SCR-004 have something to detect.

Each copy keeps the upstream project's own LICENSE file. Copyright in that code
belongs to its original authors, and it is reproduced here under those licences
for research purposes only.

The commit message on every commit names the negative and the rule it violates.
